# تصنيف الفواكه باستخدام VGG16

مشروع تعلّم عميق منظّم مبني على ملفك الأصلي، ويستخدم نقل التعلّم ثم الضبط الدقيق لتصنيف صور الفواكه والخضروات ضمن فئات مجموعة البيانات.

**الحالة:** المشروع مجهّز بالكود والتوثيق. لا تتضمن الحزمة نموذجًا مدرّبًا أو نتائج دقة فعلية؛ تُنتج هذه الملفات بعد التشغيل. راجع `docs/VALIDATION.md` لمعرفة الفحوص المنفّذة.

## البداية على Windows

1. فك ضغط الملف وافتح مجلد `fruit-classification-vgg16` في VS Code.
2. استخدم Python 3.12 وافتح Terminal داخل المجلد.
3. أنشئ البيئة الافتراضية:

```bat
python -m venv .venv
```

4. في طرفية Command Prompt فعّلها:

```bat
.venv\Scripts\activate.bat
```

إذا لم تستخدم تفعيل البيئة، يمكنك تشغيل الأوامر باستخدام `.venv\Scripts\python.exe` بدلًا من `python`.

5. ثبّت المتطلبات:

```bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip check
```

6. نفّذ تنزيل البيانات ثم التدريب ثم التقييم:

```bat
python -m src.download_data
python -m src.train
python -m src.evaluate
```

التنزيل يحتاج إنترنت ومساحة تخزين. أول تدريب يحتاج تنزيل أوزان ImageNet أيضًا. التدريب على CPU قد يستغرق وقتًا طويلًا؛ حجم الإدخال الصغير لا يجعل VGG16 نموذجًا خفيفًا.

## تجربة صورة جديدة

بعد التدريب، استبدل المسار بصورة حقيقية على جهازك:

```bat
python -m src.predict --image "C:/Users/YourName/Pictures/fruit.jpg" --top-k 3
```

النتيجة تعرض أكثر الفئات ترجيحًا. درجة Softmax لا تعني ضمان صحة التوقع، والنموذج لا يرفض الفئات غير المعروفة تلقائيًا.

## استخدام الـNotebook

```bat
python -m pip install -r requirements-notebook.txt
jupyter notebook notebooks/fruit_classification.ipynb
```

شغّل الخلايا بالترتيب. يمكن استخدام المشروع في Colab بعد رفع مجلده وتثبيت المتطلبات، لكن بيئة Colab الجاهزة قد تختلف عن إصدار Python المستهدف وتحتاج ضبطًا أو إعادة تشغيل.

## أين أعدّل الإعدادات؟

عدّل `config.json`:

| الإعداد | الوظيفة |
| --- | --- |
| `image_size` | ارتفاع الصورة وعرضها؛ البداية 64 × 64 |
| `batch_size` | عدد الصور في الدفعة؛ البداية 16 |
| `head_epochs` | الحد الأقصى لعصور تدريب رأس التصنيف |
| `fine_tune_epochs` | الحد الأقصى لعصور الضبط الدقيق |
| `fine_tune_block` | كتلة VGG16 المراد تعديل أوزانها؛ البداية block5 |
| `output_dir` | مكان حفظ النموذج وبيانات تشغيله |
| `reports_dir` | مكان نتائج التقييم والرسوم |
| `seed` | بذرة العشوائية |

التدريب يرفض الكتابة فوق مجلد تشغيل غير فارغ. عند إعادة التجربة غيّر `output_dir` إلى مجلد جديد، وغيّر `reports_dir` للاحتفاظ بالتقارير السابقة.

## ما الذي ستحصل عليه بعد التشغيل؟

- `models/run_vgg16/best_model.keras`: النموذج المختار حسب أقل خسارة تحقق بين المرحلتين.
- `class_names.json`: أسماء الفئات بالترتيب المرتبط بمخرجات النموذج.
- `config.json` و`environment.json`: إعدادات التجربة وبيئة التنفيذ.
- `reports/metrics.json`: مقاييس الاختبار الكامل.
- `reports/classification_report.csv`: مقاييس كل فئة.
- `reports/predictions.csv`: التوقع الصحيح والمتوقع لكل صورة اختبار.
- `reports/figures/`: منحنيات التدريب ومصفوفة الالتباس وأمثلة التنبؤ.

قد يكون أفضل نموذج من المرحلة الأولى إذا لم يحسّن الضبط الدقيق الأداء. لا نختار النموذج باستخدام بيانات الاختبار.

## ما الذي تغير عن ملفك الأصلي؟

تم فصل الأكواد إلى وحدات قابلة لإعادة الاستخدام، وتوحيد معالجة VGG16 دون القسمة على 255، وإلغاء حدود الخطوات الثابتة، وتثبيت ترتيب الاختبار، وحفظ النموذج وأسماء الفئات، وربط منحنيات مرحلتي التدريب على محور زمني متصل، وتحديث الشرح ليطابق ما يفعله الكود.

لا تستخدم أي نتائج قديمة بوصفها نتائج لهذه النسخة؛ المعالجة المسبقة تغيرت وتحتاج إعادة تدريب.
