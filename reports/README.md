# Experiment reports

This directory intentionally contains no claimed benchmark results. `src.train` writes `figures/training_curves.png`. `src.evaluate` writes:

| File | Content |
| --- | --- |
| `metrics.json` | Full-test accuracy, F1, cross-entropy, sample count and model hash |
| `dataset_summary.json` | Runtime counts for all three splits |
| `classification_report.csv` | Per-class precision, recall, F1 and support |
| `predictions.csv` | Relative image paths, true/predicted labels and scores |
| `confusion_matrix.json` | Raw counts and class ordering |
| `figures/confusion_matrix.png` | Row-normalized confusion matrix |
| `figures/sample_predictions.png` | Six seeded random test examples |

Keep reports from each experiment in a distinct directory. Only publish results generated by actual runs. Review image redistribution rights before publishing the sample-predictions image, since it includes dataset photographs.
