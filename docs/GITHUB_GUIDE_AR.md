# رفع المشروع إلى GitHub

## قبل الرفع

- فك الضغط وافتح المجلد الداخلي `fruit-classification-vgg16`.
- ابدأ بقراءة `README_AR.md` ثم شغّل الاختبارات.
- يمكنك نشر الكود الآن مع إبقاء حالة النتائج «لم تُقَس بعد» كما هي.
- بعد التدريب والتقييم، أضف النتائج الحقيقية والرسوم إلى README.
- تأكد من نسب المواد التعليمية الأصلية إلى مصدرها إن كانت التجربة مستندة إلى دورة.
- لا ترفع البيانات الكاملة أو البيئة الافتراضية أو أسرار الحسابات.

## باستخدام GitHub Desktop

1. أنشئ مستودعًا محليًا جديدًا باسم `fruit-classification-vgg16`.
2. انسخ محتويات المجلد المفكوك إلى مجلد المستودع، بما في ذلك `.gitignore` و`.github`.
3. راجع قائمة الملفات المتغيرة؛ يجب ألا تتضمن `data/raw` أو ملفات `.keras`.
4. أنشئ أول Commit بوصف مثل `Prepare reproducible VGG16 fruit classification project`.
5. اضغط Publish repository وحدد إن كنت تريد المستودع عامًا أو خاصًا.
6. راجع صفحة المستودع للتأكد من ظهور README وشغّل تبويب Actions لمتابعة الاختبارات.
